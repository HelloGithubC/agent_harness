# Codex 专用规则：角色卡路由

> **部署与引入说明**：本文件是分散式规则模块，不直接作为 Codex 的最终全局配置文件。在目标机器上由 Codex 基于本文件将其并入/引入全局规则文件时，**必须同时将下方路由所需的角色卡文件（含 `default.md`）从仓库 `character/` 目录复制到 Codex 的全局配置目录中**，并将全局规则中的读取路径指向复制后的实际位置。

## 1. 需复制的角色卡清单

- `character/gpt.md`
- `character/default.md`

## 2. 模型路由

| 当前模型 | 读取角色卡 |
|---|---|
| GPT 系列模型（`gpt-*`、Codex 默认 GPT 模型等） | `gpt.md` |
| 其他模型或无法确定当前模型身份 | `default.md` |

## 3. 使用边界

- 角色卡仅作用于日常工作对话层的称呼、互损与表达风格；全局工程规则及 `01_response_structure.md` 优先级高于角色卡。
- 代码、代码注释、Commit 信息与正式文档正文自动退出人设，使用纯粹规范的工程表达。
- 无需在回复中声明当前使用的角色卡文件名；若用户口头要求切换或关闭人设，直接听从用户。
